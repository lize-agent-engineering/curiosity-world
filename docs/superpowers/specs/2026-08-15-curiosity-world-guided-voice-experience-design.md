# Curiosity World 语音引导探索体验设计

> 日期：2026-08-15
>
> 状态：待快速确认
>
> 目标：在现有多 Agent 生成系统上，以最短链路形成可公开体验的声画互动闭环。

## 1. 核心体验

面试官打开公开链接后，只能点击三个预设问题进入已验证的演示：

- 月亮为什么跟着我？
- 恐龙为什么会消失？
- 为什么会下雨？

自由问题输入不是当前面试能力。受本次笔试时间与 AI Coding 工具额度限制，它被列为后续 P0：需先完成受控场景生成、真实浏览器验证及公网发布验收，才能在产品中开放。

提交后，系统召集不同能力的 Agent，生成受知识包约束的故事阶段和可操作页面。进入页面后，语音引导 Agent 根据当前故事阶段、孩子的语音回答和页面操作，逐步提出问题、给予提示并推动探索完成。结束后，家长页只根据真实行为事件生成复盘。

产品的完整闭环是：

```text
输入问题
  → 多 Agent 协作生成
  → 语音讲述当前任务
  → 孩子说话或操作
  → 页面产生确定性声画反馈
  → 引导 Agent 回应并推进
  → 完成探索
  → 家长证据复盘
```

## 2. 阶段范围

### 2.1 生成阶段

复用现有问题建模、知识设计、互动设计、质量复核与确定性编译能力，新增结构化故事设计产物。故事设计只负责：

- 生成三至四个连续探索阶段；
- 为每个阶段声明开场旁白、目标动作、引导问题、提示层级和完成条件；
- 引用知识设计产物和白名单交互能力；
- 不生成代码、物理规律或开放式科学结论。

生成页继续展示真实的能力阶段和结构化结论，不展示隐藏思维链，不用聊天气泡模拟 Agent 思考。

### 2.2 体验阶段

新增一个持续在线的探索引导 Agent。它只读取：

- 当前活动体验版本和故事阶段；
- 当前阶段允许的知识事实与提示；
- 孩子的语音转写、选择和操作事件；
- 已完成目标与下一步合法动作。

它只输出结构化引导指令：旁白文本、意图分类、反馈类型、提示级别和阶段推进决定。页面状态机验证指令后才能执行。Agent 不能修改知识规则、物理关系、完成条件或任意跳转阶段。

### 2.3 声画交互

- 语音旁白是主要信息通道，字幕是同步辅助信息。
- 孩子可以用语音回答，也可以点击、选择或拖动。
- 提供重听、跳过当前旁白和重新录音。
- 无法可靠识别时明确请孩子再说一次，不猜测答案。
- 页面操作后立即产生确定性视觉变化；关键动作配简短反馈音。
- 引导反馈不得只说“正确”或“错误”，应指出刚才发生的可观察现象。
- 不依赖孩子认识完整汉字或拼音才能推进主路径。

首轮复用现有 CSS 场景和互动控件，只增加必要的高亮、状态动效、语音状态和反馈音。不制作复杂虚拟人、3D、视频或电影级动画。

## 3. 首轮交付切片

“月亮为什么跟着我”作为第一条完整语音引导纵向切片，包含：

1. 语音故事开场；
2. 孩子语音或点击完成预测；
3. 引导孩子移动观察者并比较路灯、远山和月亮；
4. 根据操作结果提出迁移问题；
5. 孩子用语音或选择解释发现；
6. 引导 Agent 给出基于行为的结束反馈；
7. 家长页展示语音回答摘要与操作证据。

平衡支撑和光线路径继续保持当前可操作版本。本阶段不同时深度改造三个知识族，但新增协议必须允许后续复用同一引导循环。

## 4. 语音实现边界

优先复用仓库已有 ASR、TTS、播放控制和服务端模型路由，不新增并行媒体框架。浏览器麦克风权限只在孩子主动点击说话时申请。

语音失败遵循 fast-fail：

- ASR 不可用或录音失败：显示明确错误并允许重新录音；
- TTS 生成失败：显示同步字幕和重试入口，但不把字幕宣称为语音成功；
- 引导模型输出非法：保持当前阶段，不使用固定话术冒充模型响应；
- 网络中断：保留已完成的本地行为事件，恢复后从当前阶段继续。

公开部署由服务端提供已配置的模型和语音能力。访客不输入 API Key，也不进入模型设置才能体验主路径。

## 5. 数据与协议

新增的最小结构化对象为：

- `StoryDesignArtifactV1`：生成阶段的故事阶段设计；
- `GuidanceTurnRequestV1`：当前阶段、有效事件和孩子输入；
- `GuidanceTurnResponseV1`：旁白、反馈、提示和推进决定；
- `ChildVoiceEventV1`：录音状态、转写结果和关联阶段，不保存原始录音作为默认行为。

每次引导响应绑定体验版本、故事阶段和触发事件。过期版本、错误阶段或未知事件触发的响应必须被拒绝。

## 6. 儿童安全与表达

- 只支持批准知识包内的问题与故事发展。
- 不进行无限制闲聊，不要求孩子提供姓名、学校、住址等个人信息。
- 语音转写只作为当前体验输入和行为证据，默认不持久化原始音频。
- 6–7 岁每次旁白只表达一个动作；8–10 岁每次最多表达一个动作和一个观察问题。
- 卡住时按“重复任务 → 指向操作对象 → 给出现象线索”三级提示，不能直接代替孩子完成。

## 7. 验收标准

首轮完成必须同时满足：

1. 首页预设问题能够进入真实多 Agent 生成流程；
2. 故事设计产物经过严格 Schema、知识引用和阶段完整性检查；
3. 月亮体验能够播放旁白并显示同步字幕；
4. 孩子能够录制语音，系统能够将转写交给引导 Agent；
5. 引导 Agent 能根据至少一次语音回答和一次页面操作推进故事；
6. 非法推进、知识越界和过期响应被确定性拒绝；
7. 刷新后能够恢复当前体验版本、故事阶段和行为事件；
8. 家长复盘区分语音转写事实、页面操作事实和知识建议；
9. Playwright 覆盖输入、生成、旁白、模拟语音转写、页面操作、阶段推进、完成和刷新恢复；
10. 公开部署主路径无需访客配置 API Key。

## 8. 明确不做

- 复杂虚拟人、口型同步和角色动画；
- 3D 世界、视频生成或实时图像生成；
- 开放式儿童聊天机器人；
- 关卡、积分、排行榜或奖励经济；
- 三个知识族同时进行完整声画重制；
- 长期儿童能力画像；
- 用预生成结果冒充实时 Agent 生成或运行时引导。

## 9. 实施顺序

1. 故事设计与引导回合契约；
2. 生成管线加入故事设计能力；
3. 确定性体验状态机和引导响应校验；
4. 复用现有 TTS/ASR 建立语音输入输出；
5. 月亮案例完成三至四阶段引导闭环；
6. 行为事件、恢复和家长复盘；
7. 浏览器端到端验收与公开部署门禁。
