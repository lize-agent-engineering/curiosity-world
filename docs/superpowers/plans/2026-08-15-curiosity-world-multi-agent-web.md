# Curiosity World Multi-Agent Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 Moon 单模型 Spike 演进为 Web-only 的 Curiosity World：五能力首次生成、受控修改、三个知识模型族、确定性运行、可恢复版本与可追溯家长证据。

**Architecture:** 保留 Curiosity World 的模型解析、服务端异步任务、iframe 加固和 IndexedDB 基础，但以 Curiosity 自有的 V2 领域契约替换单次作者模型。Agent 只交换严格 JSON 产物；确定性校验器和知识族编译插件拥有最终否决权，候选仅在运行握手通过后激活。

**Tech Stack:** Next.js 16、React 19、TypeScript、Zod 4、Dexie、Vitest 4、Playwright 1.58、现有 Tailwind 与 UI primitives。

## Global Constraints

- 产品仅支持 Web；儿童年龄必须为 6–10 岁。
- 首次生成角色固定为 `curiosity.question-modeler`、`curiosity.knowledge-designer`、`curiosity.interaction-designer`、`curiosity.quality-reviewer`；修改角色固定为 `curiosity.revision-planner`。
- 模型不得输出 HTML、JavaScript、坐标公式、状态机或事件协议；可执行行为只能由确定性编译插件提供。
- 无模型时失败码为 `MODEL_UNAVAILABLE`；非法输出、超时或拒绝不得切换模板或其他模型。
- 测试模型只能由明确测试环境变量启用；未执行真实模型门禁时状态必须为 `LIVE_MODEL_PENDING`。
- 体验版本不可变；候选只有通过 iframe 就绪握手后才能激活，失败候选保留失败码，旧活动版本继续可用。
- 6–7 岁主要指令单句不超过 16 个汉字、同时最多两个核心变量、主要任务不超过四步。
- 8–10 岁主要指令单句不超过 28 个汉字、同时最多三个核心变量、主要任务不超过五步。
- 主要触控目标最小 44×44 CSS 像素，颜色对比满足 WCAG AA，并支持 `prefers-reduced-motion`。
- 用户可见界面不得出现课程、教师、同学、课堂、章节、幻灯片、白板、PBL、课堂 TTS 或视频导出语义。
- 所有失败遵循 fast-fail；不得复制旧版本、通用课程或固定体验作为兜底。
