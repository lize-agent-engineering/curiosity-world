## 一、这是什么

家长输入孩子问的一个"为什么"和孩子的年龄，三个智能体现场**规划、写代码、验收**，产出一个孩子能亲手操作的探索网页——先猜一猜、动手试、再看懂为什么。做完之后接着说话就能改，每一轮留成一个版本，可回滚、可从旧版本长新分支，也可以整页下载带走。

题目要的是"通过智能体驱动的方式完成代码（应用）生成"，同时明说**不考察"用 Atoms 做 Atoms"**。所以这里交的不是一个通用生成器，而是一个有具体用户、具体场景的垂直产品——它的应用是**真正被生成出来的代码**，不是把配置填进固定模板。

同一套引擎去掉领域指引就是通用生成器（`mode: 'general'`，接口、提示词、测试都在），作为平台可扩展性的证明；首页不放这个入口，主线只留一条。

## 二、实现思路与关键取舍

### 2.1 三个智能体，各自只做一件事

| 角色 | 职责 | 输出形态 | 为什么这样切 |
| --- | --- | --- | --- |
| `studio.planner` | 把孩子的问题变成可验收的探索方案，并交出「孩子该弄明白的因果关系」与「必须避开的常见错误说法」 | 严格 JSON | 需求→方案是理解问题，结构化输出能强约束字段 |
| `studio.coder` | 写整个页面 | **流式纯文本** | 代码不该塞进 JSON 字符串；纯文本不受结构化输出的 provider 限制，模型池更宽，且能一行行流式呈现 |
| `studio.reviewer` | 按教育 rubric 验收，第一条查知识对不对 | 严格 JSON | 判定要可机读，findings 要能直接喂回 coder |

三段之间是**清晰的中间产物**，而且在界面上都能展开看到：planner 的方案、reviewer 的结论与 findings、这一轮走了哪条修改路径、以及**实际应用的编辑块 diff（逐行 -/+）**。多智能体不是黑箱协作，是可核查的分工。

### 2.2 生成质量：四层机制，不靠"祈祷模型发挥"

这是整个项目里我最先验证、投入最多的部分。UI 是在质量验证通过之后才动工的。

1. **领域提示词体系**。教育模式下 coder 拿到的是"给孩子的探索页面"的规矩：至少两种会改变画面状态的交互（纯翻页不算）、先让孩子猜再揭示答案、一个换情境的迁移挑战、明确的结束画面、底部一块「给家长看」。年龄决定语言预算：4–6 岁几乎不用字，9–12 岁可以读完整句子。
2. **写进提示词的设计系统与沙箱现实**。`:root` 色板变量、4px 间距刻度、三态交互、system-ui 字体栈、触控优先；外加沙箱的真实约束——`alert/confirm/prompt` 会被屏蔽、页面自身发起的下载会被拦、没有网络。这些是"看起来对但跑不了"的高频来源。
3. **有牙齿的 reviewer**。知识错误直接判 blocker；还检查是不是真互动、有没有一上来就把答案写在屏幕上、是否适龄。findings 注入下一轮 coder 提示词。
4. **运行时错误回灌**。预览页真实报的错（含 srcDoc 解析期的同步错误，靠重放握手补齐）挂到版本上，下一轮生成自动带上。

### 2.3 增量修改：定点编辑优先，全量重写兜底

修改已存在的应用时，coder 输出 search/replace 编辑块。服务端应用规则**故意严格**：SEARCH 必须在原文中唯一命中、多块之间不得重叠、必须产生变化，**不做模糊匹配**。

理由：有全量重写兜底，"差不多匹配上了"的静默错误比一次干净的失败糟糕得多。所有编辑块先在**原始文档**上定位再从后往前拼接，因此应用顺序无关，重叠能被检测出来而不是互相破坏。

降级链：**编辑块失配 → 带着应用器的错误指引重试一次定点编辑 → 仍不中才全量重写（一次）→ 再失败才明确报错**。应用器把每种失败都写成模型可执行的指引（"请重新从当前 HTML 里逐字复制…"），所以重试是有的放矢的。走了哪条路径记在 `Version.editMode`，界面上连同实际 diff 一起可展开。

这条重试是**被真实数据逼出来的**：教育样本里 2 次回退的失败码全是 `EDIT_BLOCK_NOT_FOUND`（模型输出了块但对不上原文），重写一份 20KB 页面比重试一次贵得多，而且会丢掉"无关区域一字不动"的保证。

### 2.4 旁白：一个调用点，两种实现

孩子可能不识字，所以页面要能念出来。统一契约是 `window.curiositySay('…')`，页面自带 `speechSynthesis` 保底实现并用 `||` 守卫：

- **下载带走单独打开** → 用页面自己的声音，照样能读；
- **在工作台里** → 宿主垫片抢先定义同名函数，`||` 保留宿主版本，改用配置好的童声 TTS；
- **TTS 挂了** → 宿主把这句话回传给页面，页面用自己的声音念，而不是直接哑掉。

### 2.5 版本树

`parentVersionId` 构成树。**回滚只改指针**，历史一律不覆盖；在旧版本上继续改会长出新分支。存储是"读→变换→CAS 写"，变换全是纯函数，并发冲突会被拒绝而不是覆盖，输的一方在赢的一方之上重放。

### 2.6 信任边界与运行架构

- 客户端只发**问题文本**和**基于哪一版**；当前 HTML 永远由服务端从存储读，模型只回编辑块。
- 预览 iframe 是 `sandbox="allow-scripts"`，**刻意不加** `allow-same-origin`——两者同时给等于沙箱失效。
- Web 进程只创建/读取任务，生成由独立 worker 用租约推进；Studio 与 Curiosity 两条循环同进程、互不拖死。
- 流式：worker 按 ≥500ms / ≥2KB 节流把代码写回任务，客户端 `?since=` 增量拉取——30KB 文档不会每 500ms 重传。

### 2.7 明确的取舍

| 取舍 | 选择 | 理由 |
| --- | --- | --- |
| 产物形态 | **单文件 HTML**，不做多文件/依赖安装/真实构建 | 一次生成即可运行、可预览、可整份 diff、可下载带走；多文件需要构建与执行沙箱，收益不在"生成质量"这条主线上 |
| 修改机制 | 定点编辑块 + 全量重写兜底 | 定点编辑保住"无关区域一字不动"，重写保住成功率 |
| 模糊匹配 | 不做 | 有兜底时，静默错配比干净失败更贵 |
| 结构化输出 | 只给 planner / reviewer | coder 纯文本，模型池更宽、可流式 |
| 审查失败 | 仍然交付 | 一次 revise 给一轮返工机会；第二次仍 revise 或 reviewer 自己答不出来，都照常交付并把结论标出来。质量门不该把能用的产物毁掉 |
| 分类失败 | 落 `general` | 永不拒绝。分类只做路由不做门禁 |
| 家长摘要 | 由生成页面自带「给家长看」区块 | PRD 原本要求它来自统一事件协议，但自由生成的 HTML 保证不了外部约定。页面自带的版本诚实、可做、不依赖模型遵守宿主 API |
| 第一版的受约束管线 | 代码与 158 个测试保留，界面不再暴露（`/curiosity` 挂归档说明） | 它是 v1 路线：模型填配置、固定场景渲染。保留是为了让取舍过程可查 |
| 账号体系 | 不做 | 沿用 access-code + `CURIOSITY_PUBLIC_MODE` |

## 三、当前完成程度

### 做了

- **主流程**：孩子的问题 + 年龄 → 三智能体生成 → iframe 预览 → 对话式增量修改 → 版本切换/回滚/分支 → 一键下载带走。
- **任意问题都能进**：不再限于相对运动、平衡受力、光路三族。
- **生成过程可见**：三阶段命名进度 + 代码流式写出 + 中间产物（方案 / 审查结论 / 修改路径 / 编辑块 diff）可展开。
- **旁白**：页面自带朗读 + 工作台童声覆盖 + TTS 故障回退。
- **运行时错误闭环**：沙箱垫片捕获 → 去重上报 → 挂到版本 → 下一轮提示词自动携带。
- **数据持久化**：项目、版本树、对话、生成任务全部落盘，命名数据卷，容器替换不丢。
- **失败路径**：编辑块失配→带指引重试→重写回退、外链 HTML 被拦、修改轮 planner 失败沿用旧方案、worker 租约过期任务回收重跑——都有测试。
- **工程门禁**：prettier / eslint / tsc / **450 单测** / build / 2 个 Playwright e2e（全链路，用受控测试模型，不联网）。
- **真实模型验证**：6 个跨领域儿童问题、5–11 岁，各跑创建 + 修改，12 次全部成功。首次生成通过率 83%、旁白契约遵守率 100%、编辑块直接命中 67%、修改通过率 100%，审查 6/6 pass。产物 HTML 与报告见 `evidence/studio/education-2026-08-19/`。

### 没做

- 多文件项目、依赖安装、真实构建（单文件是刻意取舍）。
- 素材上传（图片 → 探索）。
- 统一事件协议驱动的家长摘要（现在由页面自带）。
- 账号体系、内容商城、长期学习数据。

### 已知局限

- **单次创建 p95 483s（8 分钟），没有达到我自己定的 240s 门槛**，最快的一个也要 269s。教育页面比通用应用重（18–23KB，要画场景、要旁白、要预测与迁移环节）。没有调门槛让它变绿；缓解手段是命名阶段 + 代码流式让等待可读，真正的解法（分块并行生成）列在下面第 5 条。
- 生成质量随模型波动。两类偶发故障已用重试兜住：结构化输出失败（planner/reviewer 各重试 3 次，修改轮还会沿用上一版方案）、以及 **coder 调用整轮空转**（接受请求后一个字都不吐，耗尽超时返回空——生产上撞到过一次，现在空输出会重试一次；有部分输出的不重试，那是真答案）。
- 旁白依赖模型遵守 `curiositySay` 契约。实测 6/6 遵守，但不是硬保证；没念的页面会被记成校验警告并进入重试。

## 四、如果继续投入，扩展与优先级

1. **好奇心地图**（PRD 推荐的衍生能力，首页星图已是雏形）：把孩子问过的问题连成一条兴趣路径，从"一次生成"变成"持续的知识网络"。这是最能把一次性演示变成留存产品的一步。
2. **素材上传**：孩子指着一样东西问"这是什么"，拍照直接生成探索。输入端从文字扩到图像，体验差距最明显。
3. **统一事件协议**：给沙箱一个受控事件桥，让家长摘要从"页面自己写"变成"孩子真实操作的可追溯记录"，回到 PRD 的原始要求。
4. **编辑块命中率**：已经加了"失配后带指引重试一次再回退重写"（本轮实测失败码全是 `EDIT_BLOCK_NOT_FOUND`，即模型输出了块但对不上原文）。下一步是给 coder 的当前 HTML 加行号。
5. **并行/分块生成**：长文档按区块并行生成再拼装，直接砍掉大部分等待时间。
6. **一键分享**：把某个版本导出成公开只读链接，家长直接发给孩子。

## 五、对照评估维度

**完成度** —— 主流程闭环可用，五道工程门禁 + e2e 全绿，**450 个单测**覆盖到失败路径（编辑块失配与重试、外链拦截、租约回收、规划失败降级）。真实模型 12 次运行零失败。数据落命名卷，容器替换不丢。

**工程思维** —— 任务按"最危险的一环先验"拆：编辑块应用器 → 管线与提示词 → **真实模型 GO/NO-GO 门** → 存储 → API/worker → UI → 错误回路 → 上线，UI 在质量证据拿到之后才动工。技术选型都写了理由（为什么 coder 不用结构化输出、为什么不做模糊匹配、为什么单文件）。复杂度控制体现在：引擎与外壳分离，教育模式和通用模式共用同一条管线，只换提示词。

**用户体验** —— 首页只有一件事：写下孩子的问题。年龄是记住的设置不是第二个输入。等待期有命名阶段和一行行写出来的代码，不是转圈。修改就是接着说话。历史记录做成星图，越改越亮。产物能下载带走。全程中文，文案按家长口吻写。

**创新性** —— ①**教育垂直 + 真代码生成**：不是又一个通用生成器（题目明说不考察这个），而是把生成能力放进一个有真实用户的场景。②**旁白的双实现契约**：一个调用点，宿主接管则用童声 TTS，下载带走则用页面自己的声音——让"可带走"对不识字的孩子真正成立。③**星图**：把历史记录做成产品的记忆与回访理由，也是好奇心地图的雏形。④**中间产物全部可见**：包括实际应用的编辑块 diff，让"多智能体协作"变成看得见的事实而不是宣传语。

**可交付性** —— 在线链接可直接体验，首页已预先生成 4 个探索，评审打开即可上手；README 中英双份说明本地运行与门禁；`docs/verification/studio-gate.md` 记录人工验收全过程，含验收中发现并修掉的 10 个问题；`evidence/studio/education-2026-08-19/` 存放真实模型的 12 份产物 HTML 与量化报告，门槛在跑之前就写死在 `lib/studio/spike.ts`。**其中延迟一项实测没过，如实记在证据里并说明了原因与解法，没有调门槛让它变绿。**

## 六、本地运行

```bash
pnpm install
cp .env.example .env.local   # 至少填 OPENROUTER_API_KEY
pnpm dev
pnpm worker                  # Web 自己不生成，必须同时跑
```

门禁：`pnpm check` / `lint` / `typecheck` / `test` / `build` / `test:e2e`。

真实模型门禁：`pnpm spike:studio:real`。
