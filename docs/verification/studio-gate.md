# 准出记录

这份记录写的是**验收过程**：每一条都是实际跑过、看过的结果，包括没过的那一项，以及验收
途中发现并修掉的问题。量化报告与产物 HTML 在 `evidence/studio/`。

## 一、工程门禁

`pnpm check` / `pnpm lint` / `pnpm typecheck` / `pnpm test` / `pnpm build`，外加 `pnpm test:e2e`。
每个施工切片独立过一遍，最终状态全绿：**450 个单测**、2 个 Playwright 端到端。

端到端用 `STUDIO_TEST_MODEL` / `CURIOSITY_TEST_MODEL` 的受控模型，不联网，覆盖两条链路：

- 主线：孩子的问题 → 生成 → 预览（沙箱属性断言）→ 中间产物可展开 → 下载入口 → 对话式修改
  → 版本下拉 → 回滚；
- 第一版受约束管线的原流程（仍然全绿，证明它没被动过）。

### 2.3 旁白

旁白是后加的能力，模型会不会遵守 `curiositySay` 契约此前完全没验过。**6/6 遵守**，保底
`speechSynthesis` 实现一字不差抄了，所以下载带走的页面照样能读。台词符合"先猜后揭示"：

> 「你觉得，月亮会怎样？选一个答案。」→「好，再走一次，看月亮到底怎样。」

宿主侧链路实测通过：iframe postMessage → `/api/curiosity/narration` → 200 + 真实音频
（公网实测返回 36KB `audio/mpeg`）。垫片本身有单测（消息结构、空串忽略、240 字截断、
宿主不可用时回退到页面自己的声音）。

**没有直接实测的一环**：自动化点不进沙箱 iframe 里的按钮，所以"页面调用 → 垫片发消息"
这几行没在真浏览器里点出来。它用的是和运行时错误垫片相同的 postMessage 机制，那条实测过。

### 2.4 运行时错误回路

把某版 HTML 手工改成会抛 `ReferenceError` 的页面后打开工作台：

- 预览工具栏亮起「运行报错 1」徽标；
- 展开显示 `[error] Uncaught ReferenceError: missingFunction is not defined (about:srcdoc:103)`；
- 该错误写入版本记录 `runtimeErrors`（worker 单测覆盖了它进入下一轮 coder 提示词）。

这条错误是在 srcDoc 解析期同步抛出的，能被捕获说明垫片的重放握手生效。

## 三、从验收里改出来的东西

以下问题都是**看产物、看真实响应、对照原始需求**发现的，不是靠读代码，全部补了测试：

1. planner 的 `changeNote` 被 schema 重试提示污染，「修复了上一轮因格式错误导致的校验失败」
   作为回复发给了用户 → 系统提示里明确该字段是给用户看的产品文案，重试提示自标为格式提醒。
2. 修改轮 planner 结构化输出失败会带走整次修改 → 改为沿用上一版方案继续做。
3. 编辑块围栏长度/大小写/空格抖动导致 `EDIT_BLOCK_MALFORMED` → 围栏解析放宽，SEARCH 内容
   匹配仍逐字节严格；失败时保留响应开头供诊断。
4. 教育样本里 2 次回退的失败码全是 `EDIT_BLOCK_NOT_FOUND`（输出了块但对不上原文）→ 失配后
   先带着应用器的错误指引重试一次定点编辑，两次不中才整页重写。
5. **coder 调用整轮空转**：接受请求后一字不吐，耗尽超时返回空——生产上撞到一次，整轮丢掉
   → 空输出重试一次（有部分输出的不重试）；worker 租约同时从 15 分钟提到 30 分钟，否则
   租约会在任务还在跑时过期，被回收后自己重启自己。
6. 看板首屏全是 0、贪吃蛇画布被拉成 1:2 → 对应 appKind 指引补上首屏示例数据与画布宽高比。
7. 轮询在新任务开始时没有重置 `since` 偏移，代码面板会从半途开始 → 按任务重置。
8. 项目在第一版生成后被重命名成 planner 起的应用名，导致「问过的问题」列的是应用名、孩子
   问的那句话丢了 → 项目的身份就是那句话，应用名归版本所有。
9. `font-[var(--font-…)]` 在 Tailwind 里有歧义，需要 `family-name:` 提示——圆体显示字在这个
   仓库里从来没生效过；`@theme` 里把令牌定义成 `var(--自己)` 会解析成空值。
10. 页面滚动到底会露出浅色默认背景 → body 底色跟随当前 surface。

## 四、公网部署

`docker compose up -d --build` 起 Web + worker 两个服务，共享固定名的 `curiosity-world-data`
数据卷；`CURIOSITY_PUBLIC_MODE=1` 只放行公开面。实测：

- `/`、`/curiosity`、`/api/health`、`/api/studio/projects`、`/studio/[id]` 均 200；
- `/eval`、`/classroom` 均 404（public mode 生效）；
- 部署容器内 `lib/studio/pipeline.ts` 与 HEAD 校验和一致；
- 首页已预先生成 4 个探索，评审打开即可直接体验，不必等待。
