# Curiosity World Security Policy

Please report security issues privately to the repository owner. Do not include API keys, access tokens, children’s voice recordings, transcripts, or other personal data in a public issue.

The active `main` branch is the only supported version. Reports should include the affected commit, deployment mode, reproducible steps, and observed impact without exposing secrets.

Curiosity World is designed for children. Generated content, voice input, exploration history, and parent-review evidence must be treated as sensitive data and must not be published without explicit authorization.
